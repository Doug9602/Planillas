# Planillas Texaco

Sistema de control de planillas para gasolinera Texaco.

## Tecnologías
- Backend: FastAPI (Python)
- Frontend: React
- Base de datos: PostgreSQL

## Requisitos
- Python 3.10+
- Node.js 18+
- PostgreSQL (local o Docker)

## Instalación

1. Clonar el repositorio
2. Configurar variables de entorno (copiar `.env.example` a `.env` y ajustar credenciales)
3. Ejecutar backend: `uvicorn app.main:app --reload --port 8000`
4. Ejecutar frontend: `npm start`

Ver README completo para más detalles.
